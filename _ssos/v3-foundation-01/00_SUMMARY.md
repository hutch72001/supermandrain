## 이번 안전 수정
- 메인 페이지의 두 번째 H1을 H2로 변경하여 페이지당 H1 1개 원칙 적용
- 큰 구조, URL, 파일명, 본문 순서는 변경하지 않음
- 누락 또는 빈 ALT가 있을 경우 문맥형 기본 ALT만 보완

## 실제 분석 결론
Gemini가 우려한 H1 누락은 현재 사이트에서는 발견되지 않았습니다.
190개 HTML 모두 H1이 있었고, 메인 페이지만 H1이 2개였습니다.
Title, Meta Description, Canonical, ALT도 기본 누락은 거의 없는 상태입니다.

다음 우선순위는 대량 자동수정보다 아래 항목입니다.
1. 헤딩 단계가 건너뛰는 페이지 수동 정리
2. 반복 ALT를 사진별 실제 장면 설명으로 교체
3. 하수구/누수 사진 주제 충돌 페이지 정리
4. '자세히 보기' 앵커를 문맥형 텍스트 링크로 개선
5. 시공사례를 실제 작업일지 구조로 개선
