목표
검색 결과에서 어느 핵심 진입페이지로 들어오더라도 다른 페이지를 추가 클릭하지 않고
하수구 막힘 해결 과정 또는 누수탐지 과정을 한눈에 확인할 수 있도록 PROCESS를 추가.
기존 페이지 원고/URL/H1/canonical/JSON-LD/내부링크는 유지.

적용
- 지역 종합 진입페이지: 광주 5구, 전남 시군, 전북 시군에 하수구+누수 PROCESS 추가
- 장성: V96에서 완성한 기존 표준형 그대로 유지
- 메인 / 지역별 서비스 허브 / 서비스 허브 / 증상 허브: 두 PROCESS 추가
- 장비소개 메인: V96 PROCESS 그대로 유지
- 하수구 장비 / 누수 장비: 해당 PROCESS 추가
- 싱크대/변기/메인배관/고압세척/배관내시경: 하수구 PROCESS 추가
- 누수탐지 서비스: 누수 PROCESS 추가
- 하수구/누수 증상 페이지: 해당 PROCESS 추가
- 개별 시공사례 및 개별 지역 drain/leak 하위 페이지는 이번 확장에서 수정하지 않음

PROCESS 사진 원칙
