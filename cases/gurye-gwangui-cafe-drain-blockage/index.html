구례 광의면 커피숍에서 약 6개월 간격으로 반복되던 싱크대·배수구막힘. 내시경으로 심한 유지방을 확인하고 플렉스샤프트 작업을 실시간으로 확인한 뒤 최종 깨끗해진 배관과 물 흐름까지 확인했습니다.

구례 광의면커피숍 반복 막힘배관내시경·플렉스샤프트
현장 핵심 약 6개월마다 막힘이 반복되고 최근 주기가 짧아지는 것 같다는 상담이었습니다. 내시경으로 관벽의 유지방을 직접 확인한 뒤 화면을 보면서 필요한 구간만 플렉스샤프트로 작업했습니다.

배관내시경으로 유지방 상태 확인

구례 광의면 현장에서 먼저 증상 범위와 배관 내부 상태를 확인했습니다. 눈에 보이는 배수구만 처리하지 않고 실제 화면과 배관 구조를 기준으로 필요한 작업 범위를 정했습니다.

내시경 화면을 보면서 플렉스샤프트 작업

확인된 오염과 배관 구조에 맞춰 필요한 장비를 선택했습니다. 작업 중에도 상태를 중간 확인해 이미 정리된 구간을 반복하기보다 남아 있는 문제 구간을 중심으로 진행했습니다.

작업 후 내시경으로 배관과 물 흐름 확인

작업 후에는 물이 내려간다는 이유만으로 마무리하지 않고 확인 가능한 구간을 다시 점검했습니다. 남은 오염 여부와 배수 흐름을 비교해 고객에게 작업 전후 상태를 설명했습니다.
