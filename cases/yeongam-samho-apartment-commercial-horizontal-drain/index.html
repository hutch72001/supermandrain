영암하수구막힘 삼호읍 아파트 상가 횡주관막힘, 배관내시경 후 고압세척

4~5개월마다 반복되던 아파트 상가 배수 문제. 횡주관을 내시경으로 확인하자 기름 슬러지가 관로를 크게 좁히고 있었고, 플렉스샤프트와 고압세척을 진행한 뒤 최종 내시경으로 배관 상태를 확인했습니다.

영암 삼호읍아파트 상가 횡주관플렉스샤프트·고압세척
현장 핵심영암 삼호읍 아파트 상가에서 약 4~5개월 간격으로 하수구막힘이 반복됐습니다. 단순 통수 대신 횡주관 내부를 배관내시경으로 확인하고 플렉스샤프트·부분 점검·고압세척·최종 내시경 검수 순서로 진행했습니다.

반복되는 상가 하수구막힘, 횡주관부터 확인

이전에도 배관을 뚫었지만 몇 달 뒤 같은 증상이 반복됐기 때문에 눈앞의 배수구만 처리하지 않고 상가 배수가 모이는 횡주관 상태를 먼저 확인했습니다.

내시경에서 확인된 기름 슬러지와 좁아진 물길

배관내시경 화면에서는 횡주관 내벽과 바닥에 기름성 슬러지가 두껍게 붙어 배수 단면을 크게 줄이고 있는 상태가 확인됐습니다. 플렉스샤프트로 부착물을 분리하며 배관 상태를 계속 확인했습니다.

횡주관을 확인하니 내부에 기름덩어리가 가득

상태 확인이 필요한 구간은 배관을 일부 절개해 내부를 직접 확인했습니다. 배관 안에는 단단하게 뭉친 기름 찌꺼기가 가득했고, 눈으로 확인한 상태와 내시경 진단 결과가 일치했습니다.

외부 맨홀 점검 후 고압세척으로 배관청소

외부 맨홀에서도 배관내시경으로 연결 상태를 확인한 뒤 고압세척을 진행했습니다. 상가 횡주관과 연결 오수관처럼 기름 슬러지가 넓게 누적된 경우에는 배관 내부 전체의 오염 상태를 보면서 작업 범위를 결정하는 것이 중요합니다.

고압세척 후 배관내시경으로 최종 확인

배관청소가 끝난 뒤 다시 내시경을 투입해 기름 슬러지가 제거되고 배수 공간이 확보된 상태를 확인했습니다. 단순히 물이 내려가는지만 보는 것이 아니라 작업 후 관 내부 상태까지 확인했습니다.
